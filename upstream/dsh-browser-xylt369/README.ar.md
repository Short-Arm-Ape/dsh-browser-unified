# dsh-browser

[English](README.en.md) | [中文](README.md) | [Español](README.es.md) | [Français](README.fr.md) | [Русский](README.ru.md) | **العربية**

يوفر إمكانيات تصفح ويب شاملة لـ [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) (`dsh`): التنقل، لقطات شجرة إمكانية الوصول، النقر وملء النماذج، إدارة علامات التبويب المتعددة، لقطات الشاشة، ومرفقات الصور المتوافقة مع نماذج الرؤية الحاسوبية.

إصدارات المضيف المدعومة: **dsh `0.1.0-rc.7` / `0.1.1-rc.2`**. يعتمد افتراضيًا على متصفح **Microsoft Edge** المحلي (ملف تعريف دائم + تمويه خفيف لتجاوز الكشف التلقائي) مع دعم fake-ip DNS الخاص بـ Clash / Surge.

## التثبيت

1. تأكد من تثبيت `dsh` عبر الأمر (`dsh --version`). في حال عدم تثبيته، نفّذ: `npm i -g @deepseek-ai/dsh`.
2. ثبّت الإضافات:

```sh
dsh plugin --profile web add \
  @yeesy369/dsh-browser-playwright@0.8.1 \
  @yeesy369/dsh-tool-browser@0.7.0 \
  @yeesy369/dsh-web-permission@0.6.1
```

3. أعد تشغيل `dsh web`.
4. اطلب من الوكيل الذكي فتح صفحة ويب أثناء المحادثة. إذا تطلب الموقع تسجيل الدخول، سجّل الدخول مرة واحدة في نافذة Edge المنبثقة (يتم حفظ الحالة في `~/.dsh/edge-profile`).

عند ترقية تثبيت موجود مسبقًا، استخدم أمر `plugin add` الموضح أعلاه مع تحديد أرقام الإصدارات ثم أعد تشغيل `dsh web`.

## واجهة الإعدادات (0.8.x)

يمكن الوصول إلى الإعدادات عبر **dsh Web ← الإعدادات (Settings) ← إعدادات الإضافات (Plugins)**. بعد التثبيت وإعادة التشغيل، ستظهر بطاقتان رسميتان للإضافات في هذه الصفحة (لم يعد تعديل ملف YAML يدويًا هو المسار الأساسي).

### بوابة أذونات الويب (Web permission gate)

تتحكم في أسماء النطاقات والمضيفين التي يُسمح لأدوات التصفح والجلب بالوصول إليها. تسري التغييرات **فورًا** عند الحفظ (تحديث حي).

| عنصر التحكم | الوصف |
|---|---|
| المضيفون المسموح بهم | اسم مضيف واحد في كل سطر؛ يُسمح بالوصول عند المطابقة |
| المضيفون المحظورون | اسم مضيف واحد في كل سطر؛ له الأولوية على قائمة السماح (يتضمن افتراضيًا `localhost` و `metadata.google.internal`) |
| أسماء الأدوات الخاضعة للرقابة | قائمة الأدوات التي يتم فحص وسيط `url` الخاص بها (مثل `browser_navigate` و `browser_fill` و `web_fetch`) |
| الإجراء الافتراضي للمضيفين غير المدرجين | `سماح (Allow)` أو `سؤال (Ask)` |
| الحفظ في قائمة السماح بعد الموافقة | في وضع `سؤال` وبعد موافقة المستخدم، تتم إضافة المضيف تلقائيًا إلى قائمة السماح |

يوفر أسفل البطاقة خياري **تراجع** / **حفظ**؛ كما يمكن **استعادة الإعدادات الافتراضية** للحقول المعدلة.

### نافذة المتصفح (Browser window)

تتحكم في وضع تشغيل Playwright وتوافق الشبكة. تسري التغييرات بعد **إعادة تشغيل dsh** أو عند **تشغيل المتصفح في المرة التالية**.

| عنصر التحكم | الوصف |
|---|---|
| وضع النافذة | `نافذة مرئية` / `نافذة مخفية` / `بدون واجهة (Headless)` |
| رقعة التمويه الخفيفة | مفعّلة افتراضيًا (لمسح بصمات التشغيل الآلي الشائعة) |
| السماح بـ fake-ip DNS للوكيل | مفعّل افتراضيًا؛ يسمح بإجابات `198.18.0.0/15` لـ Clash/Surge |

| وضع النافذة | السيناريوهات المناسبة | ملاحظات |
|---|---|---|
| نافذة مرئية | تسجيل الدخول اليدوي، اختبارات كابتشا، المعاينة المباشرة | يشغل نافذة على سطح المكتب |
| نافذة مخفية | متصفح حقيقي دون إزعاج سطح المكتب | لا يمكن رؤية النافذة مباشرة؛ يتطلب جلسة سطح مكتب |
| بدون واجهة | الخوادم وبيئات CI | قد تكتشفه المواقع ذات الحماية العالية؛ لا يدعم الدخول اليدوي |

توفر الحزمة الاختيارية `@yeesy369/dsh-browser-settings` لوحة في الشريط الجانبي. للاستخدام اليومي، يُفضل استخدام بطاقات إعدادات الإضافات أعلاه.

## الإمكانيات المتاحة للنموذج

| الإمكانية | الأداة / السلوك |
|---|---|
| فتح الصفحة | `browser_navigate` (مع التحقق عبر حارس الروابط) |
| قراءة الصفحة | `browser_snapshot` (تتضمن مراجع قابلة للنقر مثل `e1` و `f29e86`) |
| التفاعل | `browser_click` / `type` / `fill` / `press` / `scroll` / `wait` / `back` / `forward` |
| علامات تبويب متعددة | `browser_tabs` / `open_tab` / `switch_tab` / `close_tab` (معزولة حسب الجلسة) |
| لقطة الشاشة | `browser_screenshot` ← مرفق دائم + كتلة محتوى `image` (جاهزة لنماذج الرؤية) |
| تشغيل JS في الصفحة | `browser_evaluate` (معطلة افتراضيًا؛ تُفعّل عبر YAML / `cordis.patch.yml`) |

## النموذج الأمني

- يُسمح فقط ببروتوكول `http(s)` العام؛ ويتم حظر العناوين المحلية والحلقية وعناوين البيانات الوصفية السحابية (`packages/browser-playwright/src/url-guard.ts`).
- يُسمح افتراضيًا بـ fake-ip للوكيل (`198.18.0.0/15`) مع استمرار حظر النطاقات الخاصة الحقيقية. يمكن تعطيله في بطاقة «نافذة المتصفح».
- يتم ضبط بوابة الأذونات افتراضيًا على «سماح» للمضيفين غير المدرجين؛ يمكن التبديل إلى «سؤال» إذا كانت الموافقة اليدوية مطلوبة.
- وحدة التمويه خفيفة الوزن ولا تضمن تجاوز جميع أنظمة الحماية ضد الروبوتات.

تظل ملفات YAML / `cordis.patch.yml` صالحة لإعدادات النشر؛ وتكتب بطاقات الويب في نفس مساحة أسماء الإعدادات.

## اختياري: YAML / الإعدادات المتقدمة

يجب تعديل معظم الخيارات من خلال بطاقات الويب. يُستخدم تكوين YAML التالي للنشر الآلي فقط:

```yaml
# $DSH_HOME/settings.yaml — web-permission (تحديث حي)
web-permission:
  defaultAction: ask
  remember: true
```

```yaml
# ~/.dsh/profiles/web/cordis.patch.yml
- id: browser-playwright
  config:
    windowVisibility: visible
    stealth: true
    allowFakeIp: true
- id: tool-browser
  config:
    evaluate: false
```
