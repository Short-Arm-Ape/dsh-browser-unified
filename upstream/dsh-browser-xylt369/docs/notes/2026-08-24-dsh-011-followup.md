# 2026-08-24 — follow dsh 0.1.1 without a fake settings UI

## Why

dsh 0.1.0-rc.7 advertised plugin settings cards. On 0.1.1-rc.2, `settings.register` still only documents `base` / `applies` / `validate`, but Host **does** serve every registered namespace, including those registered with `expose: 'web'`. The Plugins tab renders the intersection of served namespaces and `settings.plugin.item` cards whose **key equals the namespace**. A Host-only plugin therefore showed a blank row; that is not an allowlist failure.

The unpublished `tsdown.client` `clientBundle` preset is the documented lazy-CJS shape:

```js
window.__ModuleLoader__.load({ id, factory: (require) => { … return module.exports } })
```

Third-party packages can emit that with esbuild. The bundle-purity gate still forbids value-importing `dsh-client-ui-settings-plugins` chrome, so cards own their staging UI.

## Decision

- Keep `expose: 'web'` and `applies: live|restart` on Host register.
- Host halves **must** `export const inject = ['settings']`. Soft `ctx.get('settings')` without inject races the settings fiber and silently skips `register`, so the Plugins tab hides the cards even when `./client` loaded.
- Ship `exports['./client']` + `dsh.client.platform: 'web'` + inject `@deepseek-ai/dsh-client-ui-settings-plugins`.
- Build `lib/client.js` with `scripts/bundle-client.mjs`. Do **not** add `react` or `@deepseek-ai/dsh-client-*` as Host `dependencies` / `peerDependencies` (that reintroduces a second `dsh-tools` copy in the profile).
- `browser_screenshot` still goes through `ctx.attachments.saveImage`; `output.render` now includes `{ type: 'image', attachment }` so Files API / vision adapters see a ContentBlock, not only JSON fields.
- URL guard defaults `allowFakeIp: true` for Clash/Surge `198.18.0.0/15` DNS answers; real private ranges stay blocked.
- `$DSH_HOME/settings.yaml` and `cordis.patch.yml` remain supported.

## Alternatives rejected

Forking apiproxy's `WEB_SETTINGS_NAMESPACES` allowlist. Vendoring the unpublished tsdown preset. Depending on a third-party settings-UI kit.
